## Pro tip: quick link override (no file edits)
Append a `?url=` query parameter to prefill the destination form link.

**Examples**
- Immediate:  
  `https://arshah18.github.io/surveys/immediate/?url=https%3A%2F%2Fforms.gle%2FREPLACE_IMMEDIATE`
- Six-month:  
  `https://arshah18.github.io/surveys/six-month/?url=https%3A%2F%2Fforms.gle%2FREPLACE_SIX_MONTH`
